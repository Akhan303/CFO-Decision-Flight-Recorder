# CFO Decision Flight Recorder — Public Showcase

Version 1.0.7. Synthetic demonstration data. Read-only public showcase.

The public Decision Record mirrors the governed, on-demand AIP recommendation evidence brief available in the authenticated Foundry application. The public control is intentionally disabled: this static release never connects to Foundry, invokes a model, or performs an action.

This repository contains only the compiled, minified, source-map-free release artifact. The private development source is intentionally excluded.
